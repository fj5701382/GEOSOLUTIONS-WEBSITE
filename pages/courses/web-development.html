About this course

Build modern, responsive websites and web applications from scratch. The course takes you from HTML and CSS basics through JavaScript to React front-ends and Node.js back-ends.

It covers both web design and full-stack development, with projects that become your portfolio.

What You'll Learn

  • HTML & CSS
  • Responsive web design
  • JavaScript
  • React
  • Node.js
  • MongoDB

What you'll get

  • Practical, project-based learning designed for real-world employment
  • Hands-on projects with expert instructors and peer support
  • A portfolio of work to show employers and clients
  • A certificate employers recognise
  • Flexible payment plans

Class schedule

Classes run on weekdays and weekends. Choose a morning, afternoon or weekend schedule when you register, and our team will confirm your class time.
